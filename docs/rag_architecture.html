Browser → Next.js Route → FastAPI RAG-Service → optionale Intent/Planner-Stufe → Tool-Registry → Reranker → LLM → SSE-Stream zurück. Alle optionalen Stufen sind über ENV-Flags abschaltbar.

Scope-Garantien: Jeder Tool-Call läuft server-side mit Filter auf user_id aus der Auth-Session — niemals aus dem Request-Body. Selektierte pdf_ids engen Retrieval zusätzlich ein. Web-Suche speichert nie in Supabase / Qdrant.

5. Optionale Features (Feature-Flags)

FlagStandardWas sich ändert
RERANKING_ENABLEDfalseCross-Encoder oder LLM-Rerank vor Context-Build
QDRANT_NATIVE_HYBRID_ENABLEDtrueServer-side Fusion statt RRF im Python
CHAT_MEMORY_ENABLEDfalseSession-Summaries als chat_memory-Quelle indexieren
PROMPT_COMPACTION_ENABLEDfalseRolling-Summary nur im Prompt, nie in Qdrant
GRAPH_ENABLED / GRAPH_EXTRACTION_ENABLED / GRAPH_RETRIEVAL_ENABLEDfalseNeo4j-Concepts + Graph-Context im LLM-Prompt
WEB_SEARCH_ENABLEDfalseTavily Web-Suche als ephemere Quelle
INTENT_CLASSIFIER_ENABLEDfalseLLM-Klassifikation der Anfrage
RETRIEVAL_PLANNER_ENABLEDfalseIntent → geordnete Retrieval-Steps
RETRIEVAL_TOOL_REGISTRY_ENABLEDfalseSchema-validierte Tool-Layer über Planner
AGENTIC_RETRIEVER_ENABLEDfalseQuality-Check + 1 Refinement-Round
